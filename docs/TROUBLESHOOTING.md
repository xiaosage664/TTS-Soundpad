# 故障排查指南

## 1. Soundpad 无法连接

现象：
- 状态栏提示 Soundpad 未运行或远程控制不可用。

检查项：
- 确认 Soundpad 已启动。
- 在 Soundpad 中开启 `File -> Preferences -> Remote Control`。
- 以普通用户身份启动本程序与 Soundpad（避免权限级别不一致）。

## 2. Edge / MiniMax 生成超时

现象：
- 生成语音时间过长或提示网络异常。

检查项：
- 确认网络可访问外网接口。
- 暂时关闭代理/防火墙后重试。
- 查看 `tts_debug.log` 中的 `request_id` 关联日志。

## 3. MiniMax Key 验证失败

现象：
- 提示 401/403 或 API Key 无效。

检查项：
- Key 是否完整复制（无多余空格）。
- 账号是否开通对应模型权限。
- 余额或套餐额度是否可用。

## 4. 发送成功但无声音

检查项：
- 输出选项是否勾选了正确通道（麦克风/扬声器）。
- Soundpad 当前设备路由是否指向目标麦克风线路。
- 尝试本地预听确认音频文件本身可播放。
